Ein *Regista* ist der tief stehende Spielmacher, der das Spiel aus dem Mittelfeld lenkt. Regista übernimmt das Denken für deinen Verein: die beste Elf, die du aufstellen kannst, der günstigste Weg durch jede SBC, der kürzeste Weg zu Galerie-Stufe 10 und Kaufen und Verkaufen zum echten niedrigsten Preis. Es sitzt direkt in der Web App, die du schon nutzt.

## Was du bekommst

| | |
|---|---|
| **Beste Elf** | Probiert jede Formation mit deinen eigenen Karten, rechnet die Chemie genau wie EA und passt Rollen und Taktik an deine Spieler an. Bewiesen am besten, nicht geraten. |
| **SBCs** | Der günstigste Kader, der die Anforderungen erfüllt, gerechnet mit dem, was jede Karte dich wirklich kostet. Eingesetzt als Entwurf; abschicken tust du selbst. |
| **Galerie** | Ein Klick zu deinem Weg auf Stufe 10, mit jedem Set und seiner Note. Ziel Stufe 10, die meisten Token pro Münze oder ein Set auf eine bestimmte Note. Karten werden gekauft und wieder angeboten, so kostet jede nur die 5 % Steuer. |
| **Galerie auf jeder Karte** | EAs eigene Spielerkarten zeigen **✓**, wenn du sie schon gesammelt hast, sonst **NEU**. |
| **Markt** | Jede Karte zum bewiesenen niedrigsten Live-Preis kaufen oder deine anbieten, direkt mit einem Button auf EAs Kartenansicht. |
| **Upgrades und versteckte Perlen** | Marktkarten, die *dein* Team innerhalb deiner Münzen klar besser machen, und Karten, die weit über ihrer Bewertung spielen. |

## Installieren (etwa 2 Minuten)

**1. Klicke oben auf Download.** Du bekommst `Regista-Setup.zip`. Wenn dein Browser fragt, wähle **Behalten**.

**2. Entpacken und Setup starten.** Rechtsklick auf die ZIP-Datei → **Alle extrahieren**, den Ordner **Regista** öffnen und **Setup Regista.cmd** doppelklicken. Windows sagt vielleicht *„Der Computer wurde durch Windows geschützt“*, weil das Setup nicht von einer großen Firma stammt. Klicke auf **Weitere Informationen** → **Trotzdem ausführen**. Danach macht es alles allein: installiert Python, falls du es nicht hast, kopiert Regista auf deinen PC, richtet die Engine ein und startet sie bei jeder Anmeldung. Regista steckt schon in der ZIP-Datei, das Setup lädt also nichts anderes herunter, um es auszuführen.

**3. Ein Klick im Browser.** Deine Erweiterungsseite öffnet sich, der Ordner ist schon kopiert. Schalte den **Entwicklermodus** ein, klicke auf **Entpackte Erweiterung laden**, drücke **Strg+V** und **Enter**. Browser lassen nur Store-Erweiterungen diesen Schritt überspringen, und du machst ihn nur einmal.

**4. Öffne die [FC 27 Web App](https://www.ea.com/de-de/ea-sports-fc/ultimate-team/web-app/).** Regista erscheint direkt in EAs Bildschirmen: in jeder SBC, unter Teams, Transfers, Verein und Einstellungen, und als Tab **Galerie** im Menü. **Alt+L** springt auf dem aktuellen Bildschirm zu Regista.

**Sprache:** Regista folgt der Sprache deiner Web App. Ändern kannst du sie unter **Einstellungen** → Regista → **Sprache**.

## Updates

Wenn eine neue Version da ist, zeigt Regista **Aktualisieren**. Ein Klick: Das Update wird heruntergeladen, auf die Regista-Release-Signatur geprüft (alles andere wird abgelehnt), ohne deine Einstellungen zu ändern installiert, und die Seite lädt neu.

## Ist das sicher?

- **Deine Daten bleiben auf deinem PC.** Die schwere Rechenarbeit läuft in einer kleinen Engine auf deinem Computer. Nichts über deinen Verein wird irgendwohin geschickt.
- **Du behältst die Kontrolle.** Nichts wird ohne deinen Klick gekauft, verkauft, angeboten oder abgeschickt, und jeder Kauf braucht einen zweiten, bestätigenden Klick.
- **Schonend zu EA.** Marktsuchen laufen mit Abstand und nur, wenn du sie startest.
- **Ehrliches Risiko.** Regista ist ein inoffizielles Fan-Tool. Das Automatisieren der Web App kann gegen EAs Bedingungen verstoßen, die Nutzung erfolgt also auf eigenes Risiko.

## Fragen

<details>
<summary><b>Funktioniert es auf dem Mac oder auf dem Handy?</b></summary>

Nein. Regista braucht Windows 10 oder 11 und Chrome oder Edge auf demselben PC.
</details>

<details>
<summary><b>Muss etwas offen bleiben?</b></summary>

Nein. Die Engine startet versteckt, wenn du dich bei Windows anmeldest. Öffne einfach die Web App.
</details>

<details>
<summary><b>Regista zeigt „Solver aus“.</b></summary>

Führe **Setup Regista.cmd** noch einmal aus. Es repariert die Installation und behält deine Einstellungen.
</details>

<details>
<summary><b>Wie entferne ich es?</b></summary>

Führe `Disable autostart.cmd` in `%LOCALAPPDATA%\Regista` aus, lösche diesen Ordner und entferne Regista auf der Erweiterungsseite deines Browsers.
</details>
